## Why Code Is the Perfect Medium for Eastern Pedagogies

DOI: 10.5281/zenodo.22049932

AI tutoring platforms treat education as a knowledge-transfer problem: the AI knows the answer, the learner needs it, the transaction completes. This mistakes access to knowledge for competence in using it. The actual bottleneck in most skill acquisition is the gap between knowing and doing — a gap no amount of description closes, because embodied competence is built, not narrated. Four pedagogical traditions engineered around this gap for centuries: Confucian li enforced full re-performance rather than editing; Guru-Shishya transmission corrected in silence, forcing the student to find the difference; Nyāya logic demanded a defensible reason rather than a right answer; Japanese mushin practice examined the automatic mind from three attentional distances to find where confidence outran competence. Each is a mechanism, not a philosophy — a specific structure that forces the learner to perform the cognitive act the tradition exists to build. This paper argues that code is the first medium in which these mechanics translate literally rather than approximately, because it makes the gap between a master artifact and a learner artifact formally measurable by a runtime neither party controls. It demonstrates the argument through four dojo bots, one per tradition, each defined as much by what it refuses to do as by what it does, and gives an honest account of what is lost in the extraction from each tradition’s original context.
